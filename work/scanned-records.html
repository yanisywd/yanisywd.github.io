Reading scanned farm records

Farmers keep years of fertiliser and field operations in paper record books. A client needed them as clean database records for carbon reports. I built the pipeline: a vision LLM reads each page, and code checks everything it returns.

Status
In production. The records feed the client’s carbon reports.
My role
The whole pipeline, from page images to database records
Stack
Python, Gemini 3.1 Pro (vision), scikit-learn, PostgreSQL
Data
230 scanned record books, 6,890 pages

How it works

  1. Read. Each page image goes to a vision LLM with a strict JSON schema: plot, crop, product, dose, unit and date. Pages with no data are skipped (1,779 of 6,890).
  2. Match. Crop and product names are messy, like “Ammo 33,5”. Hybrid retrieval finds candidates: TF-IDF on characters and words, fuzzy and substring search, and numeric cues, fused with Reciprocal Rank Fusion. An LLM then re-ranks the top 30 among 13,302 catalogue products.
  3. Check. Rules remove duplicates, fix units and flag outliers. Yields are re-read from the PDF text layer when there is one.
  4. Load. Records are written in the production schema. Before each delivery, a local replay on the exact schema must give zero field differences.

Results

6,890pages read from 230 record books
1,498checked records for 88 farms
3,138duplicate plot entries removed in 112 books, plus 618 duplicate operations
0field differences in the replay before delivery

Design choices

  • Fixed steps, not an agent. Each step can be tested and replayed. This matters when the output feeds carbon reports.
  • The LLM reads, the code decides. The model only fills the schema and ranks candidates. Rules decide what goes into the database.
  • Every client remark becomes a check. One review round found 94 matching anomalies. I fixed them and added a quality check that runs before every push.

Limits

  • The checks catch duplicates, units and outliers, not every misread digit. Client review rounds caught the rest.
  • Some data was never written in the books, like yields or cover crop biomass, so a few reports stay incomplete.
